1. HTML stands for HyperText Markup Language.
    2. HTML is used to create web pages and web applications.
    3. HTML consists of a series of elements that define the structure and content of a web page.
    4. HTML elements are represented by tags, which are enclosed in angle brackets.
    5. HTML is the backbone of the World Wide Web and is supported by all modern web browsers.
    • HTML is a markup language, not a programming language.
    • HTML is constantly evolving, with new versions and features being added over time.
    • HTML is often used in conjunction with other web technologies, such as CSS and JavaScript, to create dynamic and interactive web pages.
    • HTML is an essential skill for anyone interested in web development or design.
